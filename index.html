5-Variable K-Map (A, B, C, D, E) Exam Tip

Split into two 4-variable maps: left map for A = 0 (minterms 0–15) and right map for A = 1 (minterms 16–31). Cells in the exact same row & column of both maps are adjacent and drop variable A when grouped.

Maxterm (POS) Simplification: Group the 0s (and useful Xs) instead of 1s, complement each variable (0 → uncomplemented, 1 → complemented), and OR within each group.

BCD Adder & Excess-3 Adder

BCD Adder: Adds two 4-bit BCD digits. If binary sum > 9, condition C = K + Z₈Z₄ + Z₈Z₂ = 1 adds correction +0110 (6) via a second 4-bit adder.

Excess-3 Adder: Add 4-bit Excess-3 codes. If carry = 1, add +0011; if carry = 0, subtract 0011 (add 1101).

Quine–McCluskey (Tabulation) Minimization

Systematic tabular method ideal for 5+ variables where K-maps become cumbersome:

  1. Group by 1s count: List all minterms (and don't cares) in binary, grouped by number of 1s (Index 0, 1, 2, 3...).
  2. Pair adjacent groups: Compare minterms in group k with group k+1. If they differ in exactly 1 bit, combine them with a dash (-) and check off both.
  3. Repeat until no merges: All unchecked terms are Prime Implicants (PIs).
  4. PI Chart: Columns = required minterms (exclude don't cares), Rows = PIs. Identify columns with a single × to select Essential Prime Implicants (EPIs), then cover remaining minterms with minimum PIs.

Key IC Performance Parameters

t_pd = (t_PHL + t_PLH) / 2

Average transition time from 50% input change to 50% output response (ns).

Figure of Merit (SPP)
FOM = t_pd × P_D (pJ)

Speed-Power Product; lower pJ means better efficiency.

Fan-Out & Fan-In
Fan-Out = min(I_OH/I_IH, I_OL/I_IL)

Max standard loads driven by output (Fan-Out) vs max inputs on gate (Fan-In).

Noise Margins
NM_H = V_OH − V_IH
NM_L = V_IL − V_OL

Maximum tolerable noise voltage before logic error occurs.

Why CMOS Dominates Modern VLSI

In steady state (input 0 or 1), either the pull-up PMOS network or pull-down NMOS network is OFF — so there is no direct DC current path from VDD to GND (near-zero static power dissipation).
